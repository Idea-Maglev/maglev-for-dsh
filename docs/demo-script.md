# Maglev for DSH — 浏览器演示脚本

> 用途：在浏览器里演示 Maglev for DSH 的 GUI 界面与机械门禁。
> 前置：web 已启动（http://127.0.0.1:3099），模型 key 已配置。

## 演示目标（两样东西 + 一个门禁）

| 界面 | 说明 | 什么时候出现 |
|---|---|---|
| 📋 真相卡片 | 项目现状结构 | AI 调用 `maglev_reality_status` 后弹在会话流 |
| 🔮 结晶卡片 | 沉淀了什么 | AI 调用 `maglev_crystallize` 后弹在会话流 |
| 🚫 门禁 | 不通过检查就不能结晶 | AI 调 `maglev_crystallize` 且 spec 不完整时被拒 |

## 演示步骤

### 第 1 步：看真相卡片（20 秒）

在会话输入框发一句：

```
请调用 maglev_reality_status 工具，报告本项目的现状。
```

AI 会调用工具读项目真相，并在会话流里**弹出一张「📋 项目现状」卡片**，显示能力域、进行中主题、愿景/契约状态。

> 录屏点：卡片弹出的瞬间 + 卡片内容。

### 第 2 步：看结晶卡片（20 秒）

在会话输入框发一句：

```
请把"浏览器演示验证通过"这条结论结晶到 20_evolution/active 层。
```

AI 会调用 `maglev_crystallize`——先通过门禁检查（spec 完整），再写回真相层，并在会话流里**弹出一张「结晶卡片」**（标题 + 结论 + 写入路径 + 目标层）。

> 录屏点：结晶卡片弹出的瞬间（这是最核心的一帧）。

### 第 3 步（可选）：看门禁拦截

故意在 spec 不完整的情况下结晶（换一个没初始化 maglev 的项目 workspace），AI 调 `maglev_crystallize` 会被**门禁拒绝**（返回"spec 完整性检查未通过"）。

> 录屏点：这条体现"机械门禁不靠 AI 自觉"。

## 演示讲解要点（配字幕/旁白用）

1. **真相卡片** → "AI 读到的项目现状，对人可见"
2. **结晶卡片** → "每次迭代沉淀了什么，会话里看得见"
3. **门禁** → "不通过检查就不能结晶，是机械强制，不是 AI 自觉"

## 一句话卖点

> 装上 Maglev for DSH，一个开发者在 dsh 里就能：**可控迭代（门禁兜底）+ 知识沉淀（结晶+真相卡片）+ 随时接手（真相可读）**。
